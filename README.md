# 蓝生万象 V2 · 生纹与染

控制点构图、受蜡区约束的揉动裂纹，以及染液扩散与吸附组成的数字蜡染工坊。V1 原目录和备用档保持独立。

## 打开

双击 `index.html` 或 `打开工坊.bat`。无需安装依赖、无需联网。

推荐近期 Edge 或 Chrome；支持 WebGL 2 浮点渲染目标时使用 GPU 计算。否则自动使用低分辨率 CPU 兼容模式。若在本机预览，服务仅绑定 127.0.0.1；手机实机访问需要另外配置局域网地址。

## 创作步骤

1. **生纹**：拖动圆点移动形态；拖动小圆环转向。选“种一簇”后点布面加入新形态。最多 9 处生长点。选中形态后调舒展、疏密与蜡层；“精调位置与方向”支持键盘与滑块操作。
2. **揉蜡**：在金色图案上拖动或点按，生成局部分支裂纹。强度影响裂纹长度与宽度，蜡层厚薄影响易裂程度。最多 48 次轨迹，可撤销或清除。也可以不揉蜡，直接入染，比较完整蜡层的防染效果。
3. **浸染**：观察未覆盖布面与裂隙着色，调整染液浓度。约 2.7 秒后可结束。本轮 35 秒后自动暂停；隐藏页面时暂停推进，避免后台持续计算。
4. **脱蜡**：拖到 100% 揭晓。滑块只改变蜡层的显示，保留此前计算的纤维着色。
5. **成布**：鼠标移动改变表面光照；保存 1440×1940 PNG 作品卡或 JSON 配方，也可再次浸染继续积累颜色。手机可长按作品卡预览保存。

配方可在初始步骤导入，恢复控制点、参数与揉动轨迹，之后重新浸染。导出配方还记录了计算网格与浸染迭代日程，便于研究和核对；导入不会自动回放浸染日程，也不承诺不同 GPU 的逐像素一致。草稿存于当前浏览器 localStorage，不上传服务器。

返回调整构图会在实际修改后清除旧裂纹与染色，避免不同材料状态混用；仅返回查看不会立刻清除。

## 实际计算架构

- `patterns.js`：确定性随机种子、曲线与叶片构图、高分辨率蜡层遮罩；256² 距离场；揉动轨迹驱动、受局部边界约束的分支游走。
- `material.js`：WebGL 2 + RGBA16F 双缓冲。R 保存游离染液，G 保存吸附颜色。以通道导通率控制相邻格点的各向异性扩散、染浴供给和局部吸附。输出合成蜡层、经纬纹理、纤维着色和程序化表面光照。显示阶段双线性重建材料场，计算阶段保留最近邻采样。
- GPU 材料场：桌面 512²、手机 320²；输出画布 1024²。CPU 兼容材料场为 192²，使用同类扩散与吸附更新规则，效果较粗。
- `studio.js`：流程、指针输入、状态与配方校验、本机草稿、作品卡与 JSON 导入导出。
- `index.html`、`base.css`、`v2.css`：界面、原理说明和响应式布局。

布面的光照变化是程序化表面渲染，不是完整三维布料力学。蜡裂纹是启发式生成，不是有限元断裂仿真。所有参数未经真实材料实验标定。

AI 辅助编程、模型简化与文案整理。正式参赛需核验文化资料，填写真实团队贡献、AI 使用说明，补齐演示视频与要求的材料。

## 验证

`验证截图/验证结果.txt` 记录当前浏览器验证结果，包括材料场的实际采样统计。`verify.cjs` 使用本机 bundled Playwright 与 Edge 进行自动验证，其依赖绝对路径仅适用于本机；运行作品本身不依赖测试工具。

手机模拟测试不代替手机实机测试；显卡、温控、浏览器节能模式会影响速度。恢复绘图上下文中断时可刷新，使用已保存的设计配方重建。
